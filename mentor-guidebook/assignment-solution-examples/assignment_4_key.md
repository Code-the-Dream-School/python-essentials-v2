## Task 1: Creating and Manipulating DataFrames — **Objective**

Four sub-steps. Note that steps 2 and 3 must use `.copy()` — the tests compare each variable separately, so they must be independent DataFrames, not references to the same object.

```python
import pandas as pd

# 1. Create a DataFrame from a dictionary
task1_data_frame = pd.DataFrame({
    'Name': ['Alice', 'Bob', 'Charlie'],
    'Age': [25, 30, 35],
    'City': ['New York', 'Los Angeles', 'Chicago'],
})

# 2. Add a Salary column on a copy
task1_with_salary = task1_data_frame.copy()
task1_with_salary['Salary'] = [70000, 80000, 90000]

# 3. Increment Age by 1 on a copy
task1_older = task1_with_salary.copy()
task1_older['Age'] = task1_older['Age'] + 1

# 4. Save to CSV with no index
task1_older.to_csv('employees.csv', index=False)
```

- `index=False` on `to_csv` is required. The test asserts the re-read CSV has shape `(3, 4)`; a stray index column would make it `(3, 5)` and fail.
- Without `.copy()`, incrementing `Age` on `task1_older` also mutates the earlier DataFrames and breaks `test_increment_column` / `test_added_column`.

## Task 4: Data Cleaning — **Objective**

Seven cleaning steps applied to a copy of `dirty_data`. The order matters, and the `Hire Date` conversion is the one students most often get wrong.

```python
# 1. Read dirty data and make a working copy
dirty_data = pd.read_csv('dirty_data.csv')
clean_data = dirty_data.copy()

# 2. Remove duplicate rows
clean_data.drop_duplicates(inplace=True)

# 3. Age to numeric (bad values -> NaN)
clean_data['Age'] = pd.to_numeric(clean_data['Age'], errors='coerce')

# 4. Salary to numeric, replacing placeholders first
clean_data['Salary'] = clean_data['Salary'].replace(['unknown', 'n/a'], pd.NA)
clean_data['Salary'] = pd.to_numeric(clean_data['Salary'], errors='coerce')

# 5. Fill missing: Age with mean, Salary with median
clean_data['Age'] = clean_data['Age'].fillna(clean_data['Age'].mean())
clean_data['Salary'] = clean_data['Salary'].fillna(clean_data['Salary'].median())

# 6. Hire Date to datetime (mixed formats in the source)
clean_data['Hire Date'] = pd.to_datetime(clean_data['Hire Date'], format='mixed')

# 7. Strip whitespace, standardize Name and Department as uppercase
clean_data['Name'] = clean_data['Name'].str.strip().str.upper()
clean_data['Department'] = clean_data['Department'].str.strip().str.upper()
```

- **`dirty_data` is read raw** (before any cleaning). `test_dirty_data_read` compares it against a fresh read of the same data, so cleaning must happen on `clean_data`, not on `dirty_data`.
- **`drop_duplicates` leaves 6 rows** (the duplicated Bob row is removed from the original 7). `test_no_duplicate_rows` checks `len == 6`.
- **`Hire Date` needs `format='mixed'`** (or an equivalent per-row parse). The source mixes `2021/01/15`, `2020-03-18`, and `3/25/2019`. A plain `pd.to_datetime(...)` without `format='mixed'` produces `NaT` values, which fails `test_hire_date_notNAT`. This is the single most common failure in this task — the test even calls it out in a comment.
- **`errors='coerce'`** turns non-numeric strings (`NaN`, `unknown`, `n/a`) into NaN so they can be filled in step 5. After `fillna`, `test_no_missing_age_or_salary` requires zero nulls in both columns.
- Replacing `'unknown'`/`'n/a'` before `to_numeric` isn't strictly required (`coerce` would turn them to NaN anyway), but it matches the task wording and is harmless.
- The test only checks that `Department` is uppercase, but the task asks for both `Name` and `Department` uppercased — do both.
